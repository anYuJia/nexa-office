# Architecture Decision Records

Use ADRs for decisions that are expensive to reverse.

File naming:

- 0001-short-decision-title.md
- 0002-next-decision.md

Suggested template:

# ADR NNNN — Title

Status: Proposed | Accepted | Superseded | Rejected

## Context

What problem are we solving? What constraints matter?

## Decision

What is being chosen?

## Alternatives

What serious alternatives were considered?

## Consequences

What gets better, worse or more constrained?

## Evidence

Benchmarks, prototypes, compatibility tests or references that support the decision.

## Revisit conditions

What new evidence would justify reopening the decision?

# Nexa Office v0.1.0-alpha.1

This is the first public-facing **Alpha candidate** for Nexa Office. It is intended for testing, feedback and interoperability validation rather than production-critical documents.

## Highlights

- Native Rust + Slint desktop application with no Chromium, Electron, Tauri or WebView runtime.
- Native Docs, Sheets and Slides workspaces for supported DOCX, XLSX and PPTX subsets.
- Conservative Office compatibility policy: preserve opaque package content where possible and block unsafe destructive saves.
- Simplified Chinese / English / System-language shell with native IME paths.
- Native Open / Save As / Print / clipboard integration, recent files and crash recovery.
- Cross-platform packaging baseline for Windows, macOS and Ubuntu Linux.
- Performance, interoperability, package-size and bounded-soak gates enforced in CI.
- Product-wide UI/UX polish with typed recent-file badges and accessible compact controls.

## Supported release targets

- Windows 11 x86_64 — MSI and portable ZIP.
- macOS Apple Silicon — PKG and application ZIP.
- Ubuntu Linux x86_64 — DEB and portable TAR.GZ.

Other platforms or architectures are not part of the Alpha support contract.

## Office format scope

Nexa Office currently supports **subsets** of DOCX, XLSX and PPTX. It does not claim full Microsoft Office parity.

Notable unsupported or partial areas include:

- legacy DOC / XLS / PPT;
- VBA/macros and ActiveX/OLE execution;
- advanced Word fields, tracked changes, equations and complex floating layout;
- full Excel formula language, pivot tables, Power Query, external data connections and advanced charts;
- advanced PowerPoint animations, transitions, SmartArt, media playback and full master/theme parity.

See [Known Limitations](../KNOWN_LIMITATIONS.md) and [Support Matrix](../SUPPORT_MATRIX.md) before testing important files.

## Safety and privacy

- No mandatory telemetry.
- No required online account.
- External document links/resources are not automatically fetched.
- Crash recovery remains local.
- Unknown or unsupported destructive rewrites are blocked instead of silently discarding content.

## Alpha caveats

This candidate is **not 1.0**. Signed/notarized distribution, publisher trust, final licensing, long interactive soak evidence and the final publication decision remain release-owner responsibilities.

Always keep backups of important Office files when testing an Alpha build.
